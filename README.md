## 🛠️ Local Development

### Requirements

- Flutter SDK
- Android SDK / Android Studio
- Physical Android device (camera & GPS testing recommended)

### Run in Debug

```bash
git clone https://github.com/Starry03/dashcam.git
cd dashcam/app
flutter pub get
flutter run
```

### Build APK

```bash
cd app
flutter pub get
flutter build apk
```
